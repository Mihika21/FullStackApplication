1. Product Flow Summary
The primary journey is: authenticate → role-aware dashboard → maintain workforce master data → maintain compensation where permitted → calculate billing using protected configuration → upload monthly shift allowances where applicable → generate finance-ready reports.

6. Workforce Master Data Flows
6.1 Workforce List
Route: /workforce | All roles
Search by Employee Name, Employee ID, Domain Lead, HGV Role and authorized fields.
Filters: Engagement Type, Domain Lead, Assignment Status, GCC Presence, Employment Category.
Table includes Employee Name, Employee ID where applicable, Engagement Type, Employment Category, Domain Lead, Assignment Status, GCC Presence and Last Updated.
Click row → /workforce/[id].
Add Employee is visible only to HR Manager/HR Team Member.
6.2 Create Workforce Record
Select Add Employee.
Enter identity/employment data.
Select Engagement Type.
System dynamically applies mandatory fields.
Enter organization, sourcing, compensation and shift data as applicable.
Validate controlled values and formats.
Review billing applicability.
Save and open the new record.

6.4 Workforce Detail
Header: Employee Name, Employee ID where applicable, Assignment Status, Engagement Type.
Sections: Identity & Employment; Organization; Sourcing; Compensation; Attrition; Personal/Contact; Address; Compliance.

22. Build Notes & Confirmed Decisions
BRD is the source of truth for Phase 1 business scope.
PRD defines detailed product behavior; this document defines screen and route behavior.
Joining Bonus is confirmed as three-month amortization.
Variable Pay supports None / Flat % / Custom Amount; Flat % uses Monthly Fixed Salary.
Commercial billing rates remain protected configuration and are not included in documentation examples.
Non-GCC Fixed Bid is maintained as master data but billed outside the platform.
Phase 1 is standalone with no HRMS/payroll/SSO integration.
Architecture should remain extensible for Phase 2 dashboards and future HRMS integration.
23. App Flow Acceptance Checklist
All three roles reach only permitted screens/actions.
Dynamic mandatory fields respond correctly to Engagement Type.
Calculated billing outputs are read-only and use protected configuration.
Variable Pay and three-month Joining Bonus behave exactly as specified.
PMO monthly shift allowance overrides the default Shift Type rate when available.
CSV supports templates, validation, partial success and row-level errors.
Reports support required filters and Excel/PDF export.
Billing Configuration and User Administration are restricted to HR Manager.
Sensitive PII is protected and masked.
Audit events cover compensation, configuration, uploads and user changes.
Loading, success, validation, empty, permission and system-error states are defined.
Responsive and accessibility behavior is covered.
