Use a modular monolith in Phase 1; split services only if scale or organizational needs justify it.
Billing is deterministic and configuration-driven; commercial values are never hard-coded.
Calculated totals are not user-editable.
API authorization is mandatory even when UI controls are hidden.
Persist configuration version and calculation version so historical billing can be reproduced.
Use DTOs rather than exposing EF entities directly.
Use database constraints for uniqueness, referential integrity and numeric validity.

17. Security & Privacy
HTTPS/TLS in production; secure HTTP-only authentication cookies.
Server-side authorization on every protected endpoint.
Passwords handled by ASP.NET Core Identity PasswordHasher; never plaintext.
Sensitive PII (Aadhar, PAN, DOB, addresses, emergency contacts) restricted and masked in standard views.
Commercial billing configuration edit access restricted to HR Manager.
Secrets stored in a secret manager, never source control.
Upload extension/MIME/size controls and formula-injection protection for spreadsheet exports.
Audit logs exclude passwords, tokens and unnecessary PII.
EF Core/parameterized queries only; never concatenate SQL from user input.
Rate-limit login, reset-password and upload endpoints.
Encrypted backups and tested restore procedure.

20. Excel & PDF
Excel: Open XML SDK; include report title, billing period, filters, readable formats, frozen headers and masked/excluded sensitive fields.
PDF: server-side HTML template rendered with Microsoft Playwright; use the same report query service as Excel.
Both formats must preserve the distinction between platform-calculated billing and Non-GCC Fixed Bid billed outside the platform.
Employee-level billing should precede aggregate totals where applicable.

26. Engineering Acceptance Checklist
All three roles receive only permitted actions.
Conditional mandatory fields follow Engagement Type.
Employment Category remains separate from Engagement Type.
Billing configuration is versioned and not hard-coded.
Joining Bonus is 1/3 for the first three applicable billing months and zero thereafter.
Variable Pay supports None / Flat % / Custom Amount; Flat % uses monthly fixed salary.
PMO monthly allowance overrides Shift Type default for Employee ID + Billing Month.
CSV supports templates, validation, partial success and row-level errors.
Excel/PDF reports use the same underlying report logic.
Historical records are retained.
Sensitive PII and commercial configuration are protected.
Audit covers workforce, compensation, configuration, uploads and user changes.
2,000+ employee records are supported without material degradation in normal workflows.
