PHASE 6 — Compensation & Billing Engine
Implement compensation capture and deterministic monthly billing.
Phase Tasks
Store annual Fixed CTC in INR and derive monthly fixed salary as annual / 12.
Variable Pay modes: None, Flat %, Custom Amount.
Flat % = monthly fixed salary × configured percentage.
Salary Cost = (Fixed Salary ÷ FX Rate) + Variable Pay Amount.
Implement margin, facility, user bundle and shift allowance components.
Joining Bonus: Month 1 = 1/3, Month 2 = 1/3, Month 3 = 1/3, Month 4 onward = 0.
Fully Loaded Cost = salary cost + margin + facility + user bundle + shift allowance + joining bonus component.
PMO monthly validated shift allowance overrides Shift Type default for matching Employee ID + Billing Month.
Rebadge/Colocation: facility + user bundle only.
Non-GCC Fixed Bid: billing calculated outside platform.
Persist configuration version, calculation version and component-level results.
Phase Output
Completed compensation & billing engine with verified implementation artifacts and no unresolved critical defects.
Verification Checklist
Unit tests cover all formulas and edge cases.
Joining bonus stops after month 3.
All variable-pay modes behave correctly.
Override precedence works.
Billing is reproducible for the same month/configuration.
Non-GCC Fixed Bid has no platform-side billing calculation.

Implementation Dependency Order
Environment → Foundation → Database → Authentication/RBAC → Navigation → Workforce → Compensation/Billing → Bulk Upload → Reports → Administration/Audit → Polish → E2E/UAT → Production.
Definition of Done
Approved HGV requirements are implemented without undocumented business-rule changes.
All three roles are enforced server-side.
Workforce, compensation, billing, uploads and reports are operational.
Joining Bonus and Variable Pay rules are covered by automated tests.
Billing results are traceable to configuration and calculation versions.
Sensitive PII and billing data are protected.
Critical E2E and UAT scenarios pass.
Production deployment, monitoring, backup and rollback documentation are complete.
Decision Protocol
When implementation reaches an undocumented material decision, stop before coding that decision and request clarification. The request should identify the missing requirement, the concrete options and the implementation impact. This keeps the implementation plan from becoming an accidental source of new product requirements.
